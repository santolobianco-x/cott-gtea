# 数据集介绍
  ## 简介
  佐治亚理工学院以自我为中心的活动 (GTEA) 数据集包含七种类型的日常活动，例如制作三明治、茶或咖啡。每个活动由四个不同的人执行，因此总共有 28 个视频。对于每个视频，大约有 20 个细粒度的动作实例，例如拿面包、倒番茄酱，大约在一分钟内。
